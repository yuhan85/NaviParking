# NaviParking — Hackathon Pitch

**You don't find parking. Parking finds you.**

A self-contained 3-minute pitch deck with a live, interactive mobile demo. Open `index.html` in any browser — no build step, no backend, no API keys, works offline.

## Presenting

| Key | Action |
|---|---|
| → / Space / Enter / click | Next slide |
| ← | Previous slide |
| R | Reset the live demo |
| F | Toggle fullscreen |

## Demo flow (slides 3–4)

Destination → **Find My Parking** → 3 spots matched to your preferences (Closest / Indoor / Cheapest) → pick one → **Reserve & Go** → **Start Navigation**.

All data is deterministic mock data; every button always works.
